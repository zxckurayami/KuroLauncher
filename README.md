# KuroLauncher

Modern Minecraft launcher with a dark Japanese glassmorphism theme.

## Особенности

- Интерфейс Electron + React
- Загрузка версий Minecraft с серверов Mojang
- Установка и управление версиями
- Локальные профили с оффлайн-режимом
- Настройки Java, RAM и темы
- Тёмный минималистичный стиль с красными акцентами

## Установка

```bash
npm install
npm run dev
```

Этот запуск запускает Vite и Electron одновременно в режиме разработки.

## Сборка

```bash
npm run build
```

## Упаковка

```bash
npm run package
```

Пакет создаётся через `electron-builder`.

## Как пользоваться

1. Откройте вкладку `Versions`.
2. Установите нужную версию Minecraft.
3. Создайте профиль на вкладке `Profiles`.
4. Запустите профиль.

## CurseForge Интеграция

Лаунчер поддерживает поиск и установку модов, модпаков, ресурс-паков и шейдеров через CurseForge API.

### Настройка API ключа

1. Перейдите на [CurseForge Console](https://console.curseforge.com/)
2. Создайте аккаунт или войдите в существующий
3. Создайте новый API ключ в разделе API Keys
4. Скопируйте API ключ
5. В лаунчере перейдите во вкладку `Settings`
6. В поле "CurseForge API Key" вставьте ваш ключ
7. Нажмите "Сохранить настройки"

### Тестирование API ключа

После настройки API ключа вы можете протестировать его работоспособность:

**Через интерфейс приложения:**
1. Перейдите во вкладку "Settings"
2. Нажмите кнопку "Тестировать API ключ"
3. Посмотрите результат тестирования

**Через командную строку:**
```bash
npm run test-api
```

Если тест проходит успешно, API ключ настроен правильно. Если возникает ошибка 403, проверьте:
- Правильность API ключа
- Срок действия ключа
- Наличие необходимых прав у ключа
- Лимиты запросов к API

## Примечание

- Лаунчер скачивает файлы клиентской версии из официальных серверов Mojang.
- Оффлайн-режим использует локальный никнейм.
- Для реальной авторизации Microsoft/Mojang нужно добавить соответствующую интеграцию.
